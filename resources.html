Resources

Practical tools, written to be used.

Checklists and guides for authors who want to do the work themselves. Each one is a working document, drawn from the same research method used in an engagement, written so that an author can run it against their own book without assistance. Read the full resource inside the site, or print it to PDF from the page itself.

00How they work

Open the page. Print the file.

Each resource opens to its own page inside this site. The page shows the full checklist or guide, ready to be read, marked, and used. At the top of every resource page sits a single button labelled Print this checklist. Clicking it opens the browser's print dialog with the resource formatted for paper: white background, black text, page breaks at section boundaries, and the site navigation hidden. The PDF a reader saves from that dialog is the actual downloadable resource.

There is no file to wait for, no email address to enter, and no subscription required. The resource exists at the moment the reader asks for it, because the reader generates it themselves.

If you would prefer a version prepared for you, that is what a proposal is for. The resources on the following pages are written to be useful on their own. Some authors read them, act on them, and never need to speak to the practice. That is a good outcome.

Author Book Discoverability Checklist

A structured review of the twenty two elements that decide whether a book is found in search. Each item names what to check, what good looks like, and what to change when the check is not met. Arranged in the order a reader actually meets the book, from the search phrase through to the description on the page.

For

Independent and self published authors, first time published authors, and authors preparing to relaunch a backlist title.

A page by page audit of a book listing, from the title through to the A plus content. Fifty one checks arranged in the order a reader encounters them. Each section of the listing is read the way a stranger reads it: cover first, then title, then description, then the elements beneath the fold.
